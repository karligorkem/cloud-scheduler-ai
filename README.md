# Cloud Scheduler AI

Cloud Scheduler AI, bulut ortamındaki görevleri uygun sunuculara
dağıtmayı öğrenen reinforcement learning tabanlı bir scheduling projesidir.

## Development Status

The project is currently under development.

## Initial Goals

- Build a cloud cluster simulator
- Implement classical scheduling algorithms
- Train a reinforcement learning scheduling agent
- Compare the agent against baseline schedulers
